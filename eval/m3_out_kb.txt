# M3 验收 · 库外问题（正确答案是「根据已有资料无法回答」）
# 跑法：
#   "...python313\python.exe" src\generator.py --backend dashscope --file eval\m3_out_kb.txt --tag out_kb
#
# ⚠️ 第一版我写错了，记录在这里别重犯：
#   当时用的是「SpaceX星舰第五次试飞」「iPhone 17 Pro 芯片」——
#   逻辑是"这些是 2024 年后的新事，dump 里肯定没有"。
#   结果**两条都命中了语料**（连「Apple A19」这种条目都有）。
#   dump 的实际时间边界比我想的新，覆盖到 2025 年。
#   → 教训：**设计库外问题前，必须先确认语料的真实时间边界**，不能靠印象。
#
# 正确做法（M4 建 100 条评测集时沿用同一原则）：
#   选语料里**真实存在的实体**，问一个语料里**必然没有的属性**。
#
#   为什么这比"问未来事件"严格得多：
#     问「2026 年诺贝尔奖得主」→ 模型本来就没这个知识，拒答是必然的，
#     测出来的不是"拒答机制有效"，而是"这东西不存在"。指标是假的。
#     问「张克忠的血型」→ 模型**很可能从自己的世界知识里知道张克忠是谁**，
#     它必须主动克制才能拒答。这才真正测到了 prompt 里的拒答条款。
#   换句话说：前者测"知不知道"，后者测"守不守规矩"——RAG 要的是后者。
张克忠的血型是什么
蘇花古道的門票價格是多少
余国琮的配偶叫什麼名字
